# Референсы интерфейса

Выбранное направление — Family Console («Связь»): спокойный домашний интерфейс управления собственной инфраструктурой, где состояние и основные действия видны сразу, а технические детали доступны без доминирования.

- `home.png` — полная главная сводка;
- `connections.png` — подключения, единые ссылки, трафик и активность;
- `routes.png` — draft, правила и публикация;
- `system.png` — службы, события, домен, backup и updates.

Реализованный responsive shell использует только разделы текущей навигации; login, setup и onboarding остаются отдельными состояниями установки и входа. После создания подключения универсальная ссылка и каталог приложений показываются прямо в панели; отдельного invite-flow нет.
